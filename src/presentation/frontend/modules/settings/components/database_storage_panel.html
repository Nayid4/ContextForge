{# Reusable Hexagonal Architecture Database & File Storage Panel for Settings View #}

Arquitectura Hexagonal: Motor de Base de Datos (Ports & Adapters)

Por defecto ContextForge opera con SQLite Local Soberano (./data/contextforge.db), pero puedes conectar cualquier motor relacional o NoSQL externo mediante los adaptadores de repositorio.

Almacenamiento de Archivos & Docs-as-Code (IFileStorageGateway)

Elige dónde almacenar tus documentos .md y adjuntos binarios (PDF, imágenes, Word, Excel). Puedes mantener Local FileSystem (./docs) o sincronizar con buckets Cloud manteniendo espejo local para Git.
