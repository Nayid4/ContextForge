{# Reusable MCP & CLI Agents Integration Guide Section #}

Servidor MCP Oficial (Model Context Protocol)

SSE & STDIO

Conecta Cursor, Claude Code CLI, Antigravity y OpenAI/Codex directamente al conocimiento vivo del proyecto

SSE: http://localhost:8000/mcp/sse
search_project_context MCP Tool

Busca semántica (ChromaDB) y léxicamente (BM25) en toda la documentación Markdown y anexos del proyecto.

Args: query, project_slug="default", top_k=5

get_document_full MCP Tool

Recupera el contenido íntegro de un archivo Markdown específico (ej. ADRs, contratos API o reglas).

Args: doc_path, project_slug="default"

list_project_structure MCP Tool

Lista el árbol jerárquico completo de módulos, documentos y activos disponibles en el proyecto.

Args: project_slug="default"

Opción A: Vía Red SSE (Recomendado con FastAPI activo)

Crea el archivo .cursor/mcp.json en la raíz de tu proyecto o en Cursor Settings → MCP:

{
  "mcpServers": {
    "contextforge-docs": {
      "url": "http://localhost:8000/mcp/sse"
    }
  }
}
Opción B: Vía Proceso Local STDIO (`run_mcp.py`)

Cursor levantará automáticamente el servidor MCP bajo demanda sin abrir puertos HTTP:

{
  "mcpServers": {
    "contextforge-local": {
      "command": "python",
      "args": ["run_mcp.py"]
    }
  }
}
1. Conectar Claude Code al Servidor MCP de ContextForge

Ejecuta en tu terminal para registrar las herramientas de búsqueda documental en Claude Code:

# Conexión vía SSE (con FastAPI corriendo en puerto 8000)
claude mcp add --transport sse contextforge http://localhost:8000/mcp/sse

# O conexión vía STDIO directo:
claude mcp add contextforge -- python run_mcp.py
2. Usar Claude Code como Motor de Chat dentro de ContextForge

En Configuración → Agentes CLI Locales, selecciona Claude Code CLI:

  • Binario: claude
  • Args: -p {prompt} --output-format text
  • Además puedes generar CLAUDE.md desde Context Bundler.
1. Conectar Antigravity al Servidor MCP

Agrega el servidor MCP en la configuración de Antigravity (.antigravity/mcp.json) y genera AGENTS.md en la raíz:

{
  "mcpServers": {
    "contextforge": {
      "command": "python",
      "args": ["run_mcp.py"]
    }
  }
}
2. Usar Antigravity CLI, Codex CLI o Aider como Motor de Inferencia

Desde Configuración pulsa Auto-Detectar CLIs en PATH para habilitar:

  • Antigravity CLI: antigravity chat --message {prompt}
  • OpenAI / Codex CLI: openai api chat.completions.create -m {model} -g user {prompt}
  • Aider CLI: aider --message {prompt} --yes
LM Studio (Servidor Local OpenAI-Compatible)

1. Abre LM Studio → pestaña Developer / Local Server e inicia el servidor en el puerto 1234.
2. En Configuración → Servidores Locales HTTP selecciona LM Studio (Local Server).
3. URL Base: http://localhost:1234/v1 (No requiere API Key).

LocalAI / vLLM

1. Levanta tu contenedor LocalAI o vLLM en http://localhost:8080/v1.
2. Selecciona LocalAI / vLLM en Configuración y pulsa Probar Conexión & Latencia.
